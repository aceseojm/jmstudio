# 호순이 PWA 배포판

이 폴더 전체를 정적 웹 호스팅 서비스에 업로드하면 됩니다. 설치 기능과 서비스 워커는 `https://` 주소 또는 `localhost`에서 작동합니다.

호수니 아이콘은 브라우저 탭(`icons/favicon-32.png`)과 설치 앱(`icons/icon-192.png`, `icons/icon-512.png`)에 적용되어 있습니다.

## 포함 기능

- Chrome·Edge 데스크톱 설치형 PWA
- 오프라인 실행을 위한 전체 캐릭터 프레임 캐시
- 사용자 동의 기반 운영체제 알림
- 한국어·영어·힌디어·일본어 UI
- 닉네임, 캐릭터, 알림 설정의 기기 내 저장

## 확인 순서

1. HTTPS 주소에서 페이지를 엽니다.
2. `앱 설치` 버튼으로 설치합니다.
3. `알림 허용`을 누릅니다.
4. 물·휴식·점심·일정 시간을 저장합니다.

웹 브라우저와 설치된 PWA가 모두 완전히 종료되면 페이지 내부 타이머는 실행되지 않습니다. 완전한 백그라운드 상시 알림과 화면 전체 마우스·키보드 반응은 후속 데스크톱 앱 버전에서 제공합니다.
