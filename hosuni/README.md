# Pixel Tiger Cat MVP Demo

Interactive browser prototype for the desktop-pet product direction.

## Run

From this folder:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included behavior

- Idle animation
- Mouse-follow movement
- Separate Heart Trail particle effect
- Keyboard activity detection
- Typing animation
- Fatigue color/expression progression
- Heart Trail toggle and fatigue reset controls

This is a browser behavior prototype. A native transparent always-on-top window, global mouse/keyboard hooks, app packaging, auto-update, and code signing belong to the desktop-app phase.
